# Photos

Drop community photographs into this folder using the exact filenames below and
they appear on the site automatically — no code changes needed.

| Filename | Where it appears | Suggested subject |
| --- | --- | --- |
| `hero.jpg` | Homepage hero, top right | The community at Sunday Mass, or the choir mid-song |
| `community.jpg` | Homepage "Who We Are" section | Members together after Mass, or a cultural celebration |

If a file isn't present, the site falls back to its decorative cross / star
motif — nothing breaks and no broken-image icon appears. So you can add these
one at a time, whenever photos are ready.

## Guidance

- **Format:** `.jpg` for photographs (use `.png` only for graphics with flat
  colour or transparency).
- **Size:** roughly 1600px on the long edge is plenty. Both slots crop to fill,
  so the subject should sit near the centre.
  - `hero.jpg` renders in a square frame.
  - `community.jpg` renders in a tall 4:5 frame.
- **File weight:** aim for under ~400 KB each so pages stay fast.

## Before publishing photos of people

Please make sure you have permission from the people pictured — especially for
children, where a parent or guardian needs to agree. Many parishes handle this
with a simple photo-consent form. Once a photo is on a public website it can be
copied or indexed by search engines even if you remove it later, so it's worth
getting this right up front.
